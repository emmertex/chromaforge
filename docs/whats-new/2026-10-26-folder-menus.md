### Folder menus in one order

- A folder's right-click menu now has the same grouped order in Folders and in Local: what it does
  with the library's photos, then reorganizing the disk, the colour label, Show in Finder and Show
  Parent Folder, and removal last.
- Items that can't act right now (Move Selected Photos Here with nothing selected, Synchronize
  Folder… on a Local folder with no library photo) are grayed out with the reason instead of
  disappearing. The duplicate Create Folder Inside… and the quick Synchronize Folder entries are
  gone: use New Folder on Disk… and Synchronize Folder….
