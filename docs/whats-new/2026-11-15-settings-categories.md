### Settings lists its categories on the left
- In the Classic layout the Settings window now lists its categories down its left side, as the Modern layout does, in a window of normal size. Settings ▸ General ▸ Settings Categories puts them back in a row along the top; the Compact layout keeps the row by default and has the same choice.
- Settings ▸ General ▸ Layout lists the layouts in the order Classic, Compact, Modern.
- Settings ▸ Interface shows only the slider settings that apply: the slider style only in Classic (Compact always draws one row, Modern always pills), and Slider control only for sliders with a thumb (not pills). A note says Shift gives fine control.
- What's New opens three times as wide, so its lines read as paragraphs.
- About shows the app's name, version, licences and links; the Contributors and Models lists are gone.
- Help ▸ {app} Website and Help ▸ {app} Help open the {app} web site.
