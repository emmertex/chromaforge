### Advanced Search dialog

- **Search ▸ Advanced Search** (or `Cmd+Shift+F`) opens one modal with seven collapsible categories — File/Album/Tags,
  Item Properties, Caption/Comment/Title, Photograph Information, Geographic Position and Face Regions — that compose a
  single search: folder, keyword, type (photo / raw / video), edited state, rating (with at-least / exactly / at-most),
  flag, colour label, caption text, camera, lens, ISO, focal length, aperture, capture-date range, location, face count
  and person. Search runs the same filter the grid shows.
- The natural-language bar and the CLIP model are a later change.
