### Settings ▸ Notifications
- A new **Notifications** page, after Interface, holds the on-screen overlay's settings, which moved out of Interface and Controls, and a new set of settings for the messages at the bottom of the window.
- **In Develop** and **Elsewhere** choose which changes the overlay reports; either can be turned off, never both.
- Messages have their own size, opacity, position and background, and **Shown for** sets how long an information message stays; messages with a button and warnings stay a multiple of it.
- Each kind of message has a **Test** button that shows it as it is set.
