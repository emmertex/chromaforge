### The library view no longer shows a collection that is gone
- Undoing a collection's creation, redoing its deletion, or opening a library whose saved view names a deleted collection now shows All Photos instead of an empty grid with the collection's title.
- A filter can no longer name a collection that does not exist, and a smart collection saved from a view of a deleted collection is marked instead of being quietly empty.
- Photos that an undo took away are no longer acted on by commands that use the selection.
- Opening another library starts without the previous library's filter, target collection and previous photo.
