### A new Plug-in Manager
- File ▸ Plug-ins ▸ Plug-in Manager… lists plug-ins and pixel filters apart, each with its own icon, and shows the selected one's page beside the list: Settings, Permissions, About and Log for a plug-in; stage, measuring, base tone and module for a pixel filter; why it didn't load for one that failed.
- Install from File… opens the file picker, and a .wasm file dropped on the app while the window is open installs too.
- A plug-in's settings are a tab of its page: a save that fails keeps what you typed and says why.
- Show Folder opens the plug-ins folder; Cmd+Alt+Shift+, (Ctrl+Alt+Shift+, on Windows and Linux) opens the window.
