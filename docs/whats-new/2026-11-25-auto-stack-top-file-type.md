### Auto-Stack puts a raw or a JPEG on top
- **Auto-Stack by Capture Time** (Photo → Stack) has **Put on top of each stack**: *First photo in time* (as before), *Raw file* or *JPEG file*.
- With *Raw file* or *JPEG file*, each new stack shows a raw file or a JPEG (other non-raw images count as JPEG). A stack that has none keeps its first photo in time.
- The `stack.auto` command takes the same choice as `top`: `first`, `raw` or `jpeg`.
