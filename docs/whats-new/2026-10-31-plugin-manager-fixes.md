### Plug-in Manager fixes
- The Plug-in Manager opens at its usual width whatever is installed, and its edge drags it narrower as well as wider;
  long text on a page wraps to fit.
- While the install dialog waits, another module is refused with a note to finish the first, instead of replacing it.
  Installing a module that is already installed shows its entry instead of asking again.
- An open Settings tab shows what an update added and values the plug-in set itself, and *Save* keeps them.
