### Enable Auto Import and Auto Import Settings

- File ▸ Auto Import ▸ Enable Auto Import is now a working checked switch. Turning it off stops watching but remembers the folder; turning it on with no folder opens Settings ▸ Import at the Auto Import section.
- File ▸ Auto Import ▸ Auto Import Settings… opens Settings at that section, which gains an Enable Auto Import checkbox. Existing settings keep watching as before.
