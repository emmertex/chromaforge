### Profile Manager and camera profiles per body
- Settings ▸ Profiles (or Manage Profiles… in the profile menu) hides the profiles you never use from the
  menu and the browser. Each camera body in the library can have its own camera profile: its raws start
  with it when they are imported, and Apply to Photos gives it to the ones already there. Import Profiles
  now takes your own `.dcp` camera profiles too. Thanks @OneSlips.
