### Safer plug-in installs and updates
- After an update, a plug-in's page offers *Go Back to Version X*: the version it replaced comes back with its settings as they were.
- Remove asks first, and can keep a plug-in's data and settings for when you install it again.
- The install dialog names manifest fields this version doesn't know, and older pixel filters need confirming like older plug-ins.
- A plug-in and a pixel filter can no longer share an id; of two modules with one id, the first by file name loads and the other is listed, with Remove. The Plug-in Manager says when the folder holds more modules than it loads.
