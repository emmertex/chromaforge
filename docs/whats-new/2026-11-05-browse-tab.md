### The Import tab is now Browse
- The tab that browses a folder or card without importing it is called **Browse** now — that is what it does. The big
  button still says what happens to the photos: **Import {n} into {library}**.
- The bar over the photos has **Photo Grid / Grid / Detail** segments, the Library's views.
- **Develop without Import**, beside the Import button: the selected photo opens in Develop without joining the
  library — the edit goes to the photo's XMP sidecar, the catalog stays untouched. The module bar's Develop (and the D
  shortcut) does the same while a folder is browsed. Going back to Browse (or choosing any other source) brings the
  folder view back.
- The Library sidebar's **Folders** panel lists only the folders the library's photos were imported from, with their
  subfolders — no empty folders from the disk around them. A folder created on disk shows up once photos are imported
  into it; Local stays the way to browse such a folder meanwhile.
