### A plug-in's program is no longer stopped with one click
- While a plug-in waits for a program it started (a raw converter, a noise reducer), its row in the activity list names the program and the plug-in, and says that the results come back when the program closes.
- The row has no ✕ any more. Stop Waiting… asks first, and says that what the program makes from then on won't come back to the library and that the program keeps running.
