### Auto Import settings

- Settings ▸ Import ▸ Auto Import can now include the watched folder's subfolders (off by default). Hidden folders and the library's own folder are skipped, and the search stops after 16 levels or 200,000 entries.
- Auto Import also takes a file naming template for copies, a develop preset, a metadata preset and keywords, which every photo that arrives gets. Existing settings keep working unchanged.
