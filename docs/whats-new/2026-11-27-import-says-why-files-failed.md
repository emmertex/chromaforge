### An import says why files didn't come in
- When a drive stops responding during an import, the message at the end counts the files it kept out ("not imported: a drive stopped responding") instead of calling them not readable.
- A copy left unfinished (the drive stopped responding, or you pressed Cancel, while it was under way) is counted on its own, with the folder where a file may still appear outside the library.
- A batch the library couldn't add (a save that failed, for example on a full disk) is reported as not added, with the reason, instead of as unreadable photos.
- With Copy as DNG on, a raw that wasn't converted (Cancel while it waited, memory held by a drive that stopped responding, or a failed conversion) is listed in Import Warnings by reason; it was imported as its raw copy, and Convert Photo to DNG… converts it later.
