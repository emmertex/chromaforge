### More Lightroom Classic menu items work

- Edit ▸ Invert Selection, Deselect Active Photo (`/`) and Deselect Unflagged Photos (⌃⌥⇧D) change the selection as in Lightroom Classic. The Filmstrip toggle is on `F6`, as in Classic; `/` no longer toggles it.
- Library ▸ New Folder… (⌃⇧N) creates a folder on disk inside the folder chosen in the Folders panel, and Library ▸ Synchronize Folder… opens the Synchronize dialog for it.
- Photo ▸ Remove Photo from Catalog (Alt+Backspace) removes the selected photos from the catalog without asking; their files stay on disk, and it can be undone.
- File ▸ Set Quick Collection as Target (⌃⌥⇧B) makes the Quick Collection the target of `B` again.
- File ▸ Page Setup… (⌃⇧P) switches to the Print module and opens its paper choice.
- View ▸ Toggle Loupe View switches between the large view of the active photo and the grid.
