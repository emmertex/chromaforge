### Modern Settings follows the tab row
- In the Modern layout, Settings' list of sections now has one entry per tab of the Settings window — General, Import, Folders, Performance, Display, Interface, Slideshow, Faces, Profiles, AI Denoise, AI Models, Generative Fill, Shortcuts, Controls, Connections and Sync, in the same order — instead of the old grouped sections (Library, Editing, Display & Speed, …). Each section shows exactly that tab's settings, so both presentations of Settings read the same.
