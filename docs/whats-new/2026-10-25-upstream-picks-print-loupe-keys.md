### Print templates to files, brief loupe info, keyword set keys
- Print templates can be exported to a file and imported from one (`print.template.export`, `print.template.import`); a template change that can't be saved is undone.
- A slideshow can run manually: each slide stays up until the arrow keys move on.
- View Options can show the info overlay briefly when the photo changes, and can turn off the loupe's "Rendering…" message.
- Alt+0 / Alt+Shift+0 go to the next / previous keyword set.
- A shortcut declared by a newer version no longer runs alongside a command you gave the same key.
