### Import is a tab
- Import is now a tab beside Library, and the new default: pick a card, a drive or a folder on the left, cull its photos in the grid and loupe (P picks, X rejects) without adding them, then import the picks, the selection or all of them with the button over the photos. The settings on the right (copy, move or add in place, destination, renaming, presets, a preset stack, keywords, metadata, previews) are kept between sessions and can be saved as import presets. Thanks @OneSlips.
- Photos you only browse are never deleted, renamed or moved: Delete leaves them alone; reject them, or import them first.
- Prefer the import review? Turn off Settings ▸ Import ▸ Import as a tab, and Import… opens it as before.
