### Metadata menu: Revert Capture Time and Target Photo Only

- Metadata ▸ Revert Capture Time to Original puts each selected photo's capture time back to the one its file states (Exif date, with its time zone offset and sub-seconds). Photos whose file states none are left alone.
- Metadata ▸ Show Metadata for Target Photo Only makes the Metadata panel show and edit the active photo alone instead of the selection's mixed values. The choice is remembered.
