### Classic's choice submenus are live

- Library ▸ Filter by Flag, Filter by Color Label and Filter by Preset work like the filter bar and show what is filtered with a check mark.
- Metadata ▸ Keyword Set picks the keyword set (with Edit Set…), and Photo ▸ Set Keyword lists the set's nine keywords, checked when the selected photos have them.
- Map ▸ Location Filter and View ▸ Map Style, and Play ▸ Content in the Slideshow module, list their choices with the one in use checked.
- Develop ▸ Tools ▸ Target Adjustment turns on the Tone Curve, Hue, Saturation, Luminance or B&W Mix targeted adjustment (opening the right panel section), or puts it away with None.
- Tools ▸ Add to / Subtract from / Intersect Mask with start any mask kind from the menu, greyed until a mask is selected.
