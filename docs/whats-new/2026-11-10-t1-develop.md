### Develop menus: more Classic items work
- Tools ▸ Create New Mask ▸ Select People, Color Range (Shift+J) and Luminance Range start the same masks as the Masking panel's tiles.
- Tools ▸ Point Color Selector (Cmd+Alt+P) opens Color Mixer ▸ Point Color with its picker ready.
- Tools ▸ Remove Options ▸ Use Generative AI switches the Remove tool to Generative mode and back (it opens the service setup when none is set up).
- Settings ▸ Proof toggles soft proofing.
