### Develop, print and export a browsed photo without importing it
- The Browse bar's buttons are now just **Import** and **Develop**; the Photo Grid / Grid / Detail switch is gone from it (the bottom bar has the same buttons).
- Choosing Develop, Print, Export or Slideshow while browsing opens it on the photo you selected, without importing it. A file the library already has opens as its library photo.
- From a browsed photo in Develop, Print and Export now stay on it instead of jumping back to Browse; export writes it with its edits.
