### Lightroom import keeps every Copy Name and each photo's edit date
- A Copy Name on a photo that isn't a virtual copy (some people use it as a short title) now comes across from a Lightroom Classic catalog, so a smart collection "Copy Name is not empty" finds those photos. Such a photo isn't shown as a virtual copy.
- Each imported photo's edit date is now its last edit in Lightroom, instead of the time of the import, so "Edit Date is in the last 2 days" and sorting by edit date work as in Lightroom.
- Importing the catalog again brings a changed Copy Name across, and Lightroom's later settings still reach a photo that came in without any.
