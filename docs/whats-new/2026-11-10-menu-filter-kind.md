### Library ▸ Filter by Kind and Filter by Metadata

- Library ▸ Filter by Kind shows only master photos, only virtual copies, or only videos; picking the checked row again clears it.
- Library ▸ Filter by Metadata lists the Metadata filter's columns (Date, Camera, Lens, ISO…); each row adds or removes that column in the filter bar.
- `library.filter` takes `copy` (true for virtual copies, false for master photos); `view.filterColumns` takes `toggle` to add or remove one column.
