### Info boxes in the Map, Book and Print modules

- Map ▸ View ▸ Show Map Info puts a box in the corner of the map with the place at the centre of the view (from the offline place list, when it is downloaded), its position, the zoom and the map style. Show Map Key adds a legend of the symbols the map draws: photo pins, clusters, selected photos, the tracklog and saved locations.
- Book ▸ View ▸ Show Header Bar adds a strip above the pages with the book's name ("Unsaved Book" until it is saved) and its page count; Show Info Overlay adds a box with the book's size, type, page count and the current page.
- Print ▸ View ▸ Show Info Overlay adds a box under the page with the paper, the printer, "Page X of Y" and the print resolution.
- Each is a checked menu item and is remembered between sessions.
