### Profile Manager
- Manage… in the profile browser opens the Profile Manager: every look, LUT profile and camera profile in one table, your own first.
- Hide a profile to take it out of the menus, the browser and the camera profile choices; show it again with one click.
- Delete your own camera profiles (.dcp) and LUT profiles, asked in the row. Built-in profiles can be hidden, not deleted.
- Each row shows how many photos use the profile and which camera bodies start with it. Photos using a deleted profile keep working: photos on a deleted camera profile go back to the camera's default.
- None (camera profile only) in the profile browser takes the creative profile off in one click, so only the camera profile applies.
