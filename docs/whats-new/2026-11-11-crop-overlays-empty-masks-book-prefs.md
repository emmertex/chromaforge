### Choose crop guides to cycle, delete empty masks, Book Preferences
- Tools ▸ Crop Guide Overlay ▸ Choose Overlays to Cycle… picks which guides the O key steps through; at least one stays ticked.
- Photo ▸ Develop Settings ▸ Delete All Empty Masks removes the masks that select nothing, in one undo step.
- Book ▸ Book Preferences… sets what a new book starts with: fill or fit photos, auto-fill with the selected photos, filler text and the caption safe area.
