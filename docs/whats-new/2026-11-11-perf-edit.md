### Faster editing on masked photos, no freezes while exporting

- Editing photos with AI masks is faster: dragging a slider no longer recomputes and re-uploads every mask, and the AI analyses run once per photo and are shared between the loupe, the 100 % view and exports, instead of running again at every size.
- The window no longer stutters while exports or Build Previews run: on Windows the app now uses the Segment Heap, so the render workers freeing their image buffers no longer blocks the window's thread.
- After batch work (exports, Build Previews) finishes, the app frees the graphics card memory it pooled for it, on both chosen cards.
