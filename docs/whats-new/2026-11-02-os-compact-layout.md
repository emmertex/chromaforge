### Compact layout
- Settings ▸ General ▸ Layout has a third choice, Compact: the Classic panels drawn denser, with one-line slider rows, shorter section headers, tighter spacing and sharper corners, so more of the Edit panel fits on screen. Classic stays the default and looks as before. Based on work by @OneSlips.
- Holding Space no longer toggles the zoom again and again: Space is a modifier, so its key repeats are ignored (a text box still types spaces).
- Straightening, Auto straighten, a flip or a crop drag on an untouched photo keeps the crop locked to the ratio the Crop tool shows; nothing but the lock button (or A) unlocks it.
- A name typed in the Export dialog's preset name field is saved as an export preset when you press Export.
