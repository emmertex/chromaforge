### Select Landscape and Detect Objects

- Tools > Create New Mask > Select Landscape makes a mask of the sky, water, vegetation, mountains, architecture, natural ground or artificial ground in the photo. Sky, water and vegetation work from the photo itself; the other classes need the EoMT scene model (Settings > AI Models).
- Tools > Remove Options > Detect Objects: with it ticked, painting over an object with the Remove tool selects the whole object with the object model and removes it, instead of removing only what you painted. Without an object model it offers the download.
