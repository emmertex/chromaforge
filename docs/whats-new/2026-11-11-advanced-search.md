### Advanced Search

- Library > Advanced Search… (Ctrl/Cmd+Shift+F) opens a dedicated search panel with granular structured field filtering: a global word match across captions, titles, keywords and metadata, plus collapsible rule categories for file, collection and keywords; item properties (dimensions, rating, color label, aspect); caption and title; photograph information (camera, lens, focal length, ISO, shutter speed, aperture); location; audio/video duration; and faces.
- Search shows its results as a filtered grid view. Audio/video codec and frame rate are shown but not supported yet; a value the search can't read is reported, never an empty grid.
