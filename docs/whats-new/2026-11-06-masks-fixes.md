### Masks, fixes
- A mask that starts with Intersect now selects its first shape; it used to select nothing.
- Deleting a mask other than the selected one, from its row's menu, keeps the selected mask selected.
- An inverted radial mask saved by Lightroom Classic 15.6 imports inverted; it used to import with the effect inside.
- An Object or Describe mask now follows the photo's edges when it is enlarged, so raising its Exposure no longer draws a bright outline around the subject.
