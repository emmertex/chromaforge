### The Import tab shows every file on the card
- A filter set in the Library (stars, flags, a search…) no longer hides the files of the folder or card the Import tab is browsing: the filter is put aside while the tab is open and comes back when you return to the Library.
- Switching to the Modern layout (or any module) while the Import tab is open now leaves the tab cleanly, instead of leaving the screen stuck without a way back.
