### Settings search reads the whole page
- Search settings now finds a page by any text on it (headings, setting names and choices, notes), in your language, and by a setting's command id. Matches in the open page are marked.
- Matches in the open page now show in amber, with an outline, in every theme, and Settings ▸ Interface lists the Dark Theme card before the Light Theme one, in the order of the Dark Mode and Light Mode buttons above.
