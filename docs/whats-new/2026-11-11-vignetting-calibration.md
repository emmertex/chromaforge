### Vignetting Calibration
- Even out a lens's light fall-off from a reference shot, as Capture One's LCC "Uniform Light" does: Develop ▸ Lens Corrections ▸ Vignetting Calibration. **Create** measures the photo on screen as a reference; **Apply** gives a photo, or every selected photo, the reference that fits it.
- Apply picks the reference by itself: the same camera model, the same lens (a zoom at nearly the same focal length) and the same aperture. The fall-off changes with the aperture, so a reference serves only photos shot at its own aperture: you need one reference per aperture you use. Which body of the model took the reference doesn't matter. Photos without a reference at their aperture are left as they are and counted, and Apply's tooltip says which aperture is missing. The panel shows which reference a photo uses, with Show Reference.
- There is one reference per camera, lens, aperture and (for a zoom) focal length. Creating another one for the same combination asks whether to replace the old one; photos that already use the old one keep it, and undo brings the old one back. A full-frame reference also serves crop-mode shots (DX, 1:1, 16:9): a new full-frame reference can replace a crop one, while a new crop reference leaves the full-frame one in use for full-frame shots.
- It is non-destructive: the correction is part of the develop settings, with an Amount (0 to 120, 100 is the full measured correction), and Remove takes it off. It corrects light fall-off only: one gain for every colour channel, no colour cast or dust. (Library ▸ Flat-Field Correction… is a separate tool that writes corrected DNG copies.)
- Each reference is kept once per catalog and every photo that uses it refers to it; removing the reference photo, or deleting its file, keeps the correction. References travel with XMP sidecars, presets and copied settings, and every one you make is kept in a library in the settings folder for any catalog.
- Create checks first that the photo looks like a reference: only an even surface, one colour, light falling off evenly from the middle. A landscape, a sky with a bird or a starfield is refused with the reason. One that is close but not quite (a faint dust spot) asks before it is used: **Create Anyway**.
- A reference photo says so in the panel, with **Stop Using as Reference**: Apply no longer picks it, and photos that already use it keep it. The photo is then a normal photo again; Create on it makes it a reference again. Stop Using is one undo step, and undoing a Create stops using its reference too. Find references with the Library filter bar's Vignetting Reference picker or a smart collection's Vignetting Reference rule (under Develop); in the grid they carry a small marker.
- While a vignetting calibration applies, the lens profile's vignetting is off (both would correct the same fall-off); its distortion and chromatic aberration corrections stay.
- How to shoot a reference:
  - Light: an OLED screen showing white, or a real diffuser over the lens. Not an LCD or IPS screen: it darkens when seen at an angle and makes the correction too strong, more so with wide lenses.
  - Exposure: the RGB histogram's peak at about 2/3 to 3/4 of its width, no channel touching the right edge. Create reports the exact level and says when to shoot again.
  - On a screen, 1/30 s or slower, so its flicker evens out.
  - Focus at infinity, a tripod, VR off, and the same lens, focal length and aperture as the photos: one reference for each aperture you shoot at. Create notes when a Nikon raw says VR was on.
