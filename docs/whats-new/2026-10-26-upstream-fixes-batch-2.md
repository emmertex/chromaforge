### Smaller fixes
- Resetting the Profile section brings back the default profile.
- GPX track logs with XML character references in coordinates or times are read correctly.
- Saving an export or preset can no longer create a file the library would read as a photo's sidecar.
- Place names always download into the settings folder, and a crop or slider read from a sidecar is kept in range.
- Quitting on macOS removes the library lock's owner note.
