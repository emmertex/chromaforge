### Libraries
- File ▸ Libraries keeps one list of recent libraries: a library opened from the welcome window, the launch list or a script goes to the top of it too. Libraries from the older recent catalogs list are added once.
- Settings ▸ General ▸ At launch is the one setting for what opens at startup, and holding Alt (Option on a Mac) as the window appears shows the launch list once.
- File ▸ Libraries ▸ Back Up Library backs up the open library now.
- Every window about a library says library: Library Settings…, Export as Library…, Import from Another Library…, the welcome window and the backup messages. Import Lightroom or Capture One Catalog keeps its name.
