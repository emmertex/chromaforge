### Object masks with an open model
- Object masks can now run on SAM 2.1 (Meta, Apache-2.0), a 156 MB download, instead of the gated SAM 3. The masking panel's AI Models… button lists each AI mask model with its size and licence, downloads it on request and picks which one Object masks use. Automatic keeps SAM 3 when it is installed. Describe masks still need SAM 3. Ported from OneSlips' fork.
