### More Metadata filter columns, and "Unknown" can be picked (issue #777)
- The filter bar's Metadata columns can now list File Format (JPG, CR3, TIFF…), ISO, Focal Length, Aspect Ratio (as
  developed: 3:2, 4:5, 16:9…), Title, Headline, Caption, Creator, Copyright, Location, City, Country, Develop Preset
  (the presets in each photo's History) and AI Tools (Denoise, Super Resolution, Lens Blur, Smooth Skin, Subject / Sky
  / Object / People masks…).
- The Unknown row of a column is clickable: photos without a keyword, camera, label, capture date, title… can be
  shown, alone or together with values picked in the same column. Unrated in the Rating column is clickable too.
