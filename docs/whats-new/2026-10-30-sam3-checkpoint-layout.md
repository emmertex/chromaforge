### SAM 3 checkpoint files
- A SAM 3 or subject model file that stores a tensor the app never reads in another number format (a mirror's complex rotary frequencies, for example) now loads instead of being refused.
- A SAM 3 model file in Meta's original layout is named as such, with a pointer to the Hugging Face facebook/sam3 file the app reads, instead of a missing-tensor error.
