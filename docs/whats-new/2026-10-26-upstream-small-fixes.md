### Small fixes from upstream
- Clear Color Label can be given its own keyboard shortcut in Help ▸ Keyboard Shortcuts.
- A preset imported from a photo with a custom white balance now says the white balance was left out.
- A white balance edit that names only the temperature or only the tint keeps the other field's look.
- Malformed EXIF capture times are skipped, so the next valid date is used instead.
- An import rename sequence that runs out reports the remaining files as failed instead of stopping the import.
- Command-line scripts saved with a UTF-8 byte order mark (Windows PowerShell) run.
