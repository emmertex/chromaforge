# Lightroom Classic menu items still to build

The menu bar follows Lightroom Classic's: the same menus per module, items, order and keys.
The items below are in the menus already, greyed out with **Coming soon** on hover; none of them runs
anything yet. Pick one, build it, and replace its `soon.*` slot in `crates/ui-egui/src/lrc_menus.rs` with
the real command (its entry in `COMING_SOON` goes, and this file is regenerated by
`cargo test -p lcc-ui-egui lrc_menu_gaps_doc -- --ignored`).

**Size:** S = an afternoon, M = a few days, L = a week or more. **Kind:** *wire-up* = the app already
does this in a panel or dialog and the menu item only needs to reach it (often a small name dialog
or picker); *feature* = new behaviour.

Generated from the menu tables; don't edit by hand.
