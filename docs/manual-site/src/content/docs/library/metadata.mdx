- **Metadata** panel (**Window ▸ Panels ▸ Info**): file name, folder, capture time, rating, label, title, headline, caption, keywords, alt text, extended description, copyright, copyright status, rights terms, creator, location.
- **View** menu in the panel picks a field set: *Default*, *EXIF*, *IPTC*, *IPTC Extension*, *Location*, *Large Caption*, *Minimal*. **Metadata ▸ All Metadata…** shows everything.
- Edits apply to every selected photo; differing values show `< mixed >` and are left alone until typed into. One undo step.
- **Metadata presets**: **Apply**, save, rename, delete, **Import / Export Metadata Presets…** (own files, Lightroom metadata templates, XMP templates, zips).
- **Copy / Paste Metadata** (`Cmd/Ctrl+Alt+Shift+C` / `V`) and **Sync Metadata** (active photo to selection).
- **Edit Capture Time…** (**Metadata** menu): set, shift by days/hours/minutes, change time zone, use file date, or read it from the file name.
- **Rename Photos…** (`F2`): template tags with live preview, one undo step.
- **Fill Location from GPS** (reverse geocoding): offline GeoNames cities (download on request) or a Nominatim server (asks for consent). Opt-in.
- **XMP sidecars**: **Save Metadata to File** (`Cmd/Ctrl+S`), **Read Metadata from File**, **Automatically Write Changes into XMP** (**Metadata** menu). Rating, label, flag, title, caption, copyright, keywords, GPS, capture time and edits travel.
- A grid badge marks metadata changed in the catalog, on disk, or both (conflict); reading and saving ask before overwriting the other side.
- Sidecar naming: `name.xmp` or `name.ext.xmp` (**Library** preferences).
- Face names from other apps (MWG regions) are read.
