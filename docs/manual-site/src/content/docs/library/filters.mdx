- **Filter Bar** (`Shift+F`, or `\` in the grids): rating (at least / exactly / at most), pick or reject flag, colour labels, file type, edited or not, camera, lens, keyword, people. Counts show beside flags and labels.
- **Metadata columns**: the column switch shows up to six lists (Date, Camera, Lens, Label, Keyword, People, Flag, Rating, File Type, plus ISO and focal length) with counts and a search box each.
- **Enable Filters** (`Cmd/Ctrl+L`) switches the filter off and on; **Clear** resets it. The filter stays when you change collections.
- **Presets** (filter bar): save, apply and delete filter presets. **Save as Smart Collection…** keeps the filter as a collection.
- **Search Photos** box (`Cmd/Ctrl+F`): text over names, titles, keywords and more. **AI** turns it into a semantic search ("sunset over water") when an image-text model is installed.
- **Search chips** below it in Modern, such as `3+` and `Picks`, are quick filters.
- **Sort** (bottom bar, **View ▸ Sort**): capture date, import date, edit date, file name, rating, file size, random, or custom order; ascending or descending; grouping by day, month or year.
- Stacked photos and virtual copies honour the filter; **Hide Rejected Photos** filters rejects out.
- **Find Similar Photos** filters to look-alikes; **Clear Filters** returns.

<Aside type="note" title="Modern layout">
  Filter (funnel icon) and the search box with chips are on screen. Sort and grid style: **View ▸ Sort**.
</Aside>
