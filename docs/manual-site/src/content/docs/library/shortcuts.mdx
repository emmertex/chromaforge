| Key | Action |
|---|---|
| `1`–`5`, `0` | Set or clear the star rating |
| `[` / `]` | Lower / raise the rating |
| `P`, `X`, `U` | Pick, reject, clear flag |
| backtick | Cycle the flag |
| `6` `7` `8` `9` | Red, yellow, green, blue label |
| `Shift` + the above | Apply, then next photo |
| `D` / Enter | Loupe |
| `Shift+C` | Compare |
| `N` | Survey |
| `Shift+R` | Reference view |
| `Home` / `End` | First / last photo |
| `Shift` + arrows | Extend selection |
| `=` / `-` | Larger / smaller thumbnails |
| `Shift+F` or `\` | Filter Bar |
| `Cmd/Ctrl+L` | Enable / disable filters |
| `Cmd/Ctrl+F` | Search |
| `B` | Add to Quick Collection or target |
| `Cmd/Ctrl+G` / `+Shift+G` | Group / ungroup stack |
| `S` | Expand / collapse stack |
| `Cmd/Ctrl+'` | Virtual copy |
| `Cmd/Ctrl+Alt+K` | Painter |
| `Cmd/Ctrl+Shift+K` | Edit Keywords |
| `Alt+1`–`Alt+9` | Toggle keyword set keywords |
| `Cmd/Ctrl+Alt+Shift+C` / `V` | Copy / paste metadata |
| `Cmd/Ctrl+S` | Save metadata to file |
| `F2` | Rename photos |
| `Cmd/Ctrl+Shift+I` | Import |
| `Cmd/Ctrl+N` | New collection |

- Remap or disable any key in **Help ▸ Keyboard Shortcuts**.
- Text fields and open dialogs keep their keys.
- The full list of fixed keys is in that dialog.
