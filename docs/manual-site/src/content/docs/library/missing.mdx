- A **Missing** source appears in the Catalog list when files are gone; the grid badges missing photos.
- **Find Missing Photos…** (**File** or **Library** menu): pick a folder; matches by name and size, then content hash; renamed files by size and content. Look-alikes are reported, not guessed. Runs in the background, one undo step.
- **Locate Missing File…** (**Photo** menu): point one photo at its file.
- **Folders** panel: **Move Folder To…** and **Rename Folder…** relink photos; **Synchronize** imports new files and relinks moved ones.
- Metadata changed outside the app: a badge shows *changed on disk* or *conflict*; **Read Metadata from File** / **Save Metadata to File** ask before overwriting.
- Missing files are listed, never silently dropped; Delete only removes from the catalog unless you choose **Delete from Disk**.
- **Library ▸ Previews**: build or discard previews to browse without the originals.

<Aside type="note" title="Modern layout">
  **File ▸ Find Missing Photos…** and **Photo ▸ Locate Missing File…** in the ☰ menu.
</Aside>
