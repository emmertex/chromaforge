- **File ▸ Import Photos…** (`Cmd/Ctrl+Shift+I`), **Import from Folder…**, **Import from Device**: each opens the **Import Photos** review.
- **Review grid**: thumbnails with checkboxes. Duplicates (same path or content) are marked and unchecked. With several file types, one toggle per type checks or unchecks all of them (raws without the JPEGs beside them).
- **Transfer**: **Add** (leave files in place), **Copy** (into the library's Originals or any folder) or **Move** (the source is removed only after the copy is verified). Copy can also write **Copy as DNG** (lossless, verified); a raw it couldn't convert (Cancel while it waited, memory held by a drive that stopped responding, a failed conversion) is imported as its raw copy and listed by reason in **File ▸ More Imports ▸ Import Warnings…**; **Convert Photo to DNG…** converts it later.
- **Organise** copies by day, month, one folder or a custom template such as `{date:%Y}/{date:%Y%m%d}`; the example destination is shown.
- **Rename** with a template and live example; the **Tags** picker inserts `{name}`, `{seq:4}`, `{date:…}`, `{camera}`, `{lens}`, `{iso}` and more.
- **Apply on import**: develop preset, metadata preset (copyright, creator), keywords, a collection, and **Batch edits** sliders (Light, Vibrance, Clarity, Sharpening, Grain, Vignette) as one History step.
- **Drag and drop**: files or folders dropped on the window open the review (or import at once with **Settings ▸ Import ▸ Import dropped photos without review**). A card says what the drop will do.
- **Import presets**: save and reuse the dialog's settings (**Save as Preset**).
- **Raw defaults** (**Settings**): built-in, a preset, or per camera model; applied to new photos.
- Raw, JPEG, TIFF, PNG, WebP, JPEG XL, PSD and DNG are read. Unreadable files are reported, never crash the import; a batch the library couldn't add (a save that failed) is reported as "not added", with the reason, not as unreadable. Images over 512 megapixels are refused with a message giving their size and the limit. Previews are built in the background after import.
- Import runs on a worker thread with a progress row and **Cancel** in the activity stack; the whole import is one undo step.
- **Several drives or cards at once**: when the files come from more than one drive, card or network share, the review reads them side by side instead of one after another. A drive that stops answering (a pulled card, a share that dropped) doesn't hold up the others: after about 30 seconds without progress (longer for a drive that was asleep or after the computer wakes) its files are reported as "volume not responding" and the rest are read. **Cancel** returns even while a drive hangs. A file that makes the reader fail unexpectedly is reported on its own; the others still come in. Work that reads the same drive at the same time (the review beside **Reading originals** after a Lightroom import, say) shares that drive's readers and takes turns with it, instead of each adding its own.
- **A drive that stops answering during Copy or Move**: copying stops only for that card or destination drive. Files whose copy hadn't started are reported as "volume not responding"; a copy that was under way is reported as "outcome unknown", because it may still finish: the file can then appear in the destination folder without being in the library, and the original is always kept. The message at the end of the import counts these apart from unreadable files: "not imported: a drive stopped responding", and "copies left unfinished" with the folder where a file may still appear. Files the app never got to read because its file reader stopped on an internal error are counted as "not imported: the app's file reader stopped; import them again": the files are fine, and importing them again reads them. **Cancel** returns even while a drive hangs; a raw waiting to be converted by **Copy as DNG** when you cancel is kept as its raw copy, not converted. A copy that is still being written to disk, read back to check it, or converted to DNG when you cancel is finished first instead of being left unfinished; on a slow drive that can make Cancel take up to several minutes.

## Browse without importing

- **Import as a tab** (**Settings ▸ Import**, on by default): the **Import** tab is a *Browse* view. Cull a card or folder in Grid, Square Grid or Loupe, pick **Show All** or **Show Not Imported**, turn **Include subfolders** on or off (a folder browsed for the first time includes them; the choice is kept when the same folder is browsed again), then **Import** takes the picks, the selection or all (the bottom bar switches the view). **Develop** opens the selected photo without importing it, edits to its XMP sidecar, catalog untouched; **Print**, **Export** and **Slideshow** (module picker, shortcuts) do the same, and moving between them stays on that photo until you go back to Library. A file already in the library opens as its library photo.
- **Local** (left panel): browse Pictures, Desktop, Downloads, Home or any folder without importing; **Add N to My Photos** imports. Browsed photos are never deleted by Delete or Delete Rejected.
- **Eye focus strip while browsing**: Settings ▸ Interface ▸ Detail View ▸ **Show the eye focus strip while browsing a folder** (see [Settings](../../reference/settings/#detail-view-and-eye-focus-strip)); **Settings ▸ Performance ▸ Background preparation ▸ Culling** sets how far ahead browsed photos are prepared.
