---
title: Import
description: Bring photos in without moving or changing them.
---

import { Aside } from '@astrojs/starlight/components';

- **Add in place**, **Copy**, or **Move** into a folder scheme you choose.
- Raw, JPEG, TIFF, PNG, HEIC and DNG are read; unsupported cameras are reported, not crashed on.
- Apply a preset, keywords and copyright at import.
- Auto import watches a folder and brings new files in.
- Missing files are listed, never silently dropped.
- Also imports from Lightroom, Capture One and Immich.

<Aside type="note" title="Modern layout">
  Import (photos, folder, camera roll) is on screen. Lightroom, Capture One and Immich imports: **File ▸ More Imports**.
</Aside>
