- **File ▸ Import Photos…** (`Cmd/Ctrl+Shift+I`), **Import from Folder…**, **Import from Device**: each opens the **Import Photos** review.
- **Review grid**: thumbnails with checkboxes. Duplicates (same path or content) are marked and unchecked. With several file types, one toggle per type checks or unchecks all of them (raws without the JPEGs beside them).
- **Transfer**: **Add** (leave files in place), **Copy** (into the library's Originals or any folder) or **Move** (the source is removed only after the copy is verified). Copy can also write **Copy as DNG** (lossless, verified).
- **Organise** copies by day, month, one folder or a custom template such as `{date:%Y}/{date:%Y%m%d}`; the example destination is shown.
- **Rename** with a template and live example; the **Tags** picker inserts `{name}`, `{seq:4}`, `{date:…}`, `{camera}`, `{lens}`, `{iso}` and more.
- **Apply on import**: develop preset, metadata preset (copyright, creator), keywords, a collection, and **Batch edits** sliders (Light, Vibrance, Clarity, Sharpening, Grain, Vignette) as one History step.
- **Import as a tab** (**Settings ▸ Import**, on by default): the **Import** tab is a *Browse* view. Cull a card or folder in Grid, Square Grid or Loupe, pick **Show All** or **Show Not Imported**, then import picks, the selection or all. **Develop without Import** edits a browsed photo into its XMP sidecar, catalog untouched.
- **Local** (left panel): browse Pictures, Desktop, Downloads, Home or any folder without importing; **Add N to My Photos** imports. Browsed photos are never deleted by Delete or Delete Rejected.
- **Drag and drop**: files or folders dropped on the window open the review (or import at once with **Settings ▸ Import ▸ Import dropped photos without review**). A card says what the drop will do.
- **Import presets**: save and reuse the dialog's settings (**Save as Preset**).
- **Raw defaults** (**Settings**): built-in, a preset, or per camera model; applied to new photos.
- Raw, JPEG, TIFF, PNG, WebP, JPEG XL, PSD and DNG are read. Unreadable files are reported, never crash the import. Previews are built in the background after import.
- Import runs on a worker thread with a progress row and **Cancel** in the activity stack; the whole import is one undo step.
