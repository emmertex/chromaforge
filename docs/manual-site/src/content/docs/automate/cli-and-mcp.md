- Every action is a **command** with an id. The menus, keys, CLI, control channel, MCP and plug-ins all run the same ones. See [Commands](../commands/).
- **CLI** (`<cli>`): run commands, render and export without a window. See [Command line](../cli/).
- **Headless render and snapshots**: no window, no GPU. See [Headless](../headless/).
- **Control channel**: JSON lines over a local port; drive the running app. See [Control channel](../control-channel/).
- **MCP server**: let an AI agent work on your library. See [MCP server](../mcp/).
- **Actions**: record what you did, replay it on other photos. See [Actions](../actions/).
- **Plug-ins**: sandboxed WebAssembly add-ons. See [Plug-ins](../plugins/).
- **Control surfaces and MIDI**: dials and keys. See [Control surfaces](../control-surfaces/).
- **Shortcuts**: every key can be changed. See [Customise shortcuts](../shortcuts/).
