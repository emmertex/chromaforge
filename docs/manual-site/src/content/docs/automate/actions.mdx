- **Record**: type a name in the **Actions** panel and press **Record**; do the steps; stop. The steps come from the command journal.
- **Parameters**: a step value written `{{name}}` becomes a parameter asked for when the action plays.
- **Play**: runs once per selected photo (the default), then restores your selection. It stops at the first failing step.
- **Shortcut**: give a saved action a key in the panel; the desktop app plays it on that key.
- **From scripts**: `<cli> run-action NAME [param=value…] [ids=[…]]`, or the `actions.*` commands (`list`, `get`, `play`, `delete`) through MCP.
