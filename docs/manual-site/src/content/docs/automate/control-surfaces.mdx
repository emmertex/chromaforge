- **Enable**: **Edit ▸ Settings ▸ Controls ▸ Use control surfaces**. Off by default; it listens on a local port (7981 by default).
- **Logitech MX Creative Console** (Keypad and Dialpad): install the plug-in from Settings ▸ Controls (**Install the plugin**, needs Logi Options+). The plug-in asks to pair; match the six-digit code and **Approve**. Source in `packaging/logi`.
- **Loupedeck+**: set up in the same page; Loupedeck's own profiles found on the computer can be imported. Loupedeck Live / CT and Tangent panels are not built yet.
- **Profiles**: Default, Wedding, Portrait, Fashion, Landscape, Real Estate, or your own; import and export `.lcsurface`.
- **Dials** move Develop values; one turn is **one undo step**. **Keys** run any command. Pages follow the tool you use (crop, masking, remove).
- **On-screen readout**: shows the value being turned or the command a key ran. **Settings ▸ Interface ▸ On-Screen Overlay** sets size, position and when it shows.
- **MIDI** (Windows and macOS): off until you give the app a `midi.toml` map in the settings folder. Bind pitch bend, CC or notes to Develop controls (absolute or relative) or commands. `midi.reload` re-reads the file.
