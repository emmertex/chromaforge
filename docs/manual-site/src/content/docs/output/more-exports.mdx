- **File ▸ Libraries ▸ Export as Library…**: selected or all photos into a new library, with or without originals and previews. Bring them back with **File ▸ More Imports ▸ Import from Another Library…** (preview of new / changed items, a rule for changed photos).
- **File ▸ More Exports ▸ Contact Sheet PDF…**: **Paper** (A4, Letter…), **Landscape**, **Columns**, **Rows**, **Filename captions**; 150 dpi, sRGB, current edits. For layouts with more control use the [Print module](../print/).
- **File ▸ More Exports ▸ Timelapse Video…**: stills to a silent H.264 or ProRes movie (**Size**, **Frames per Photo**, **Cross-Fade Frames**, **Quality**). See [Video](../video/).
- **More Exports** also holds **Export Presets…**, **Export Keywords…**, **Export Camera Profile (.dcp)…** and **Export Look as LUT (.cube)…**.
- **Slideshow** exports PDF, JPEG or video: see [Slideshow export](../slideshow-export/).
- **Web** exports a gallery folder or uploads it: see [Web gallery](../web-gallery/).

<Aside type="note" title="Modern layout">
  All of these are in the ☰ menu under **File**.
</Aside>
