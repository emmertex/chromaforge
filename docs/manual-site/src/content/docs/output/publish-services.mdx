- **Publish Services** panel in Library's left column (Classic and Compact).
- Services: **Hard Drive**, **SFTP**, **Immich**, and plug-in services. Set up and edit each with **Edit Settings…**.
- A published collection groups its photos: **New Photos to Publish**, **Modified Photos to Re-Publish**, **Published Photos**, **Deleted Photos to Remove**.
- **Publish** renders and sends; re-publishing replaces; removing a photo deletes it at the destination.
- **Mark as Up-to-Date** clears a state without sending.
- SFTP: one folder per collection; the host key is remembered on first use.
- Immich: collections become albums; send renders, originals or both.
- 🟡 No Flickr or SmugMug services.
