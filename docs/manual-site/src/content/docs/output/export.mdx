- Open: **File ▸ Export…** (⇧⌘E), the **Export** button in the module bar. It exports the selected photos (or the open one).
- The preview of a single photo shows the loupe's own render (the thumbnail stands in until it arrives). Entering Export from Develop selects the photo on screen.
- One encoder serves the app, CLI, MCP and the web build; the file matches the preview at any size.
- Sections, in order, each folds and shows a one-line summary:
  - **Export Location**: [folder, subfolder, conflicts](../export-location/)
  - **File Naming**: [templates and tokens](../export-location/)
  - **File Settings**: [format, quality, colour space, HDR](../export-formats/)
  - **Image Sizing**: [dimensions, resolution](../export-size-sharpen/)
  - **Output Sharpening**: [screen, matte, glossy](../export-size-sharpen/)
  - **Metadata**: [what travels with the file](../export-metadata-watermark/)
  - **Watermarking**: [text or graphic](../export-metadata-watermark/)
  - **Post-Processing / After Export**: [Apple Photos](../export-formats/#after-export)
- The left column has the section jump list and the [preset column](../export-presets/).
- The bottom line summarises the result, for example "JPEG (90%) / sRGB / 8-bit · Long Edge 2048 px".
- **Ask / Folder / Next to Originals** (top right) switches the destination quickly.
- Export runs in the background and shows in the activity stack; ✕ cancels it.
- Start another export while one runs and it waits its turn: a "Waiting to export" row appears in the activity stack, ✕ on it drops it, and it starts when the one before ends.
