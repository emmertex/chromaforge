---
title: Print, slideshow, web, book, map
description: Other ways to present and place your photos.
---

import { Aside } from '@astrojs/starlight/components';

- **Print**: layouts, templates and colour-managed output.
- **Slideshow**: templates, titles, overlays and music; export a slideshow.
- **Web**: gallery export.
- **Book**: page layouts.
- **Map**: place photos on a map.
- **Contact sheet** PDF.

<Aside type="caution" title="Modern layout">
  These modules have no button on screen; the Library / Develop switch only has two names.
  Open them from **Window ▸ Modules ▸ Map / Book / Slideshow / Print / Web**. Slideshow: **Window ▸ Slideshow**.
  Print dialog: **File ▸ Print…**. Contact sheet: **File ▸ More Exports**.
</Aside>
