<Steps>
1. **Import** a folder or card. Originals are never touched.
2. **Cull** in the grid: rate, flag, reject.
3. **Develop** the keepers; every edit is a saved recipe, not a new file.
4. **Export** JPEG, TIFF or more, at any size.
</Steps>
