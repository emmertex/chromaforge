---
title: Install
description: Get Chromaforge running.
---

- Download the build for your system from the project's **Releases** page.
- macOS: open the `.dmg`, drag the app to Applications.
- Windows: run the installer, or unpack the portable zip.
- Linux: use the package for your distribution, or build with `cargo xtask install`.
- Web: open the browser build; it runs locally, nothing is uploaded.
- Updates: the app checks for new releases and tells you.
