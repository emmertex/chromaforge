- **Open it**: Settings ▸ **AI Models**, or the **AI Models…** button in the Masks panel (the dialog also opens by itself when a model is missing).
- **Download** a model with its **Download** button. Read the licence link first; nothing is fetched until you confirm. Downloads resume after an interruption, can be cancelled, and are verified; a file that does not match is deleted.

## Installing SAM 3

SAM 3 (Segment Anything with Concepts, Meta 2025) provides detailed Object clicks and enables Describe (text prompt) masks.

Meta releases the weights under the custom, non-OSI [SAM License](https://github.com/facebookresearch/sam3/blob/main/LICENSE) in a **gated** repository on Hugging Face ([`facebook/sam3`](https://huggingface.co/facebook/sam3)). Because access is gated, Chromaforge cannot download the checkpoint automatically without your Hugging Face credentials.

### 1. Request access on Hugging Face

1. Log in or create an account at [Hugging Face](https://huggingface.co/).
2. Open the [facebook/sam3 repository page](https://huggingface.co/facebook/sam3).
3. Review Meta's SAM License agreement, fill out the access form, and submit the request.
4. Wait for approval from Meta (approvals are usually granted promptly).
5. Generate a User Access Token with read permissions at [Hugging Face Settings ▸ Access Tokens](https://huggingface.co/settings/tokens) and copy your token (`hf_...`).

### 2. Destination folder

The model files belong in `models/sam3/` inside the per-user settings directory:

- **Linux**: `~/.config/<settings_dir>/models/sam3`
- **macOS**: `~/Library/Application Support/Chromaforge/models/sam3`
- **Windows**: `%APPDATA%\Chromaforge\models\sam3`

You can also point Chromaforge at any other folder in Settings ▸ **AI Models** ▸ **SAM 3 model folder**, or override it with the `<PREFIX>_SAM3_DIR` environment variable.

### 3. Install scripts

Run the script for your operating system in a terminal or PowerShell session. Replace `hf_your_token_here` with your Hugging Face access token:

<Tabs syncKey="os">
<TabItem label="Linux">

```bash
# 1. Set your Hugging Face access token
export HF_TOKEN="hf_your_token_here"

# 2. Target folder (default settings directory)
APP_DIR=$(printf '%s' "Chromaforge" | tr '[:upper:]' '[:lower:]')
DEST="${XDG_CONFIG_HOME:-$HOME/.config}/$APP_DIR/models/sam3"
mkdir -p "$DEST"

BASE="https://huggingface.co/facebook/sam3/resolve/main"
FILES="config.json vocab.json merges.txt tokenizer.json tokenizer_config.json special_tokens_map.json processor_config.json"

# 3. Download configuration and tokenizer files
for f in $FILES; do
  echo "Downloading $f..."
  curl --proto '=https' -fsSL -H "Authorization: Bearer $HF_TOKEN" -o "$DEST/$f.part" "$BASE/$f" && mv -f "$DEST/$f.part" "$DEST/$f"
done

# 4. Download weights (3.4 GB; resumes if interrupted)
echo "Downloading model.safetensors (3.4 GB)..."
curl --proto '=https' -fsSL -C - -H "Authorization: Bearer $HF_TOKEN" -o "$DEST/model.safetensors.part" "$BASE/model.safetensors"
mv -f "$DEST/model.safetensors.part" "$DEST/model.safetensors"

# 5. Verify official SHA-256 checksum
echo "Verifying model.safetensors..."
echo "6d06f0a5f84e435071fe6603e61d0b4cc7b40e0d39d487cfd4d67d8cc11cc14a  $DEST/model.safetensors" | sha256sum -c -

echo "SAM 3 installed successfully in $DEST"
```

<TabItem label="Windows">

```powershell
# 1. Set your Hugging Face access token
$env:HF_TOKEN = "hf_your_token_here"

# 2. Target folder (default settings directory)
$Dest = Join-Path $env:APPDATA "Chromaforge\models\sam3"
New-Item -ItemType Directory -Force -Path $Dest | Out-Null

$Base = "https://huggingface.co/facebook/sam3/resolve/main"
$Files = @(
    "config.json", "vocab.json", "merges.txt",
    "tokenizer.json", "tokenizer_config.json",
    "special_tokens_map.json", "processor_config.json"
)
$Headers = @{ Authorization = "Bearer $env:HF_TOKEN" }
$Sha256 = "6d06f0a5f84e435071fe6603e61d0b4cc7b40e0d39d487cfd4d67d8cc11cc14a"

# 3. Download configuration and tokenizer files
foreach ($f in $Files) {
    Write-Host "Downloading $f..."
    $part = Join-Path $Dest "$f.part"
    $final = Join-Path $Dest $f
    Invoke-WebRequest -Uri "$Base/$f" -Headers $Headers -OutFile $part
    Move-Item -Force $part $final
}

# 4. Download weights (3.4 GB)
Write-Host "Downloading model.safetensors (3.4 GB)..."
$weightsPart = Join-Path $Dest "model.safetensors.part"
$weightsFinal = Join-Path $Dest "model.safetensors"
Invoke-WebRequest -Uri "$Base/model.safetensors" -Headers $Headers -OutFile $weightsPart

# 5. Verify official SHA-256 checksum
Write-Host "Verifying model.safetensors SHA-256..."
$got = (Get-FileHash $weightsPart -Algorithm SHA256).Hash.ToLower()
if ($got -ne $Sha256) {
    Remove-Item -Force $weightsPart
    throw "Checksum mismatch! Download is incomplete or damaged."
}
Move-Item -Force $weightsPart $weightsFinal

Write-Host "SAM 3 installed successfully in $Dest"
```

### Other install methods

- **Hugging Face CLI**: If you have the `huggingface-cli` or `hf` command installed:
  ```sh
  hf auth login
  huggingface-cli download facebook/sam3 --local-dir "<target-folder>"
  ```
- **From repository source**: In a developer checkout, run the bundled installer script:
  - Linux and macOS: `HF_TOKEN=hf_... tools/install-sam3.sh`
  - Windows: `$env:HF_TOKEN = "hf_..."; .\tools\install-sam3.ps1`
- **Verification**: Restart Chromaforge or navigate to Settings ▸ **AI Models**. SAM 3 will show as installed, and Object clicks and Describe masks in the Masking panel will use SAM 3.

## Where files go

- Models live in the per-user settings folder, under `models/` (AI masks), `denoise-models/` and `ml-models/`. Per-model folders can be moved or overridden with environment variables listed in the project documentation.
- Face and search caches sit beside the library (rebuildable, not part of the catalog).

## Hardware

- **GPU** is used where it gives the same result faster: Metal on macOS for SAM 3, wgpu (Vulkan, DirectX 12, Metal) for denoise, search and face models. Elsewhere SAM runs on the CPU.
- Settings ▸ **AI Denoise** ▸ Speed: Automatic, Graphics card or Processor. Settings ▸ **AI Models** and **Performance**: choose the device for search (Automatic, a named card, or CPU). Settings ▸ **Faces**: run face models on the CPU only.
- A GPU error falls back to the CPU for that job; the reason is shown.
- SAM 3 is large: it uses several GB of memory and is unloaded after 10 idle minutes.
- A denoise batch can use a second graphics card, or another computer's card over a network (advanced; see the project documentation).
