## Packages
| Platform | Download |
|---|---|
| macOS | `.dmg` (universal); ad-hoc signed unless the release is notarised |
| Windows | `.msi` installer (x64; an Arm64 build is tested in CI), and a portable zip |
| Linux | AppImage, `.deb`, `.rpm`, Flatpak bundle (not on Flathub), `.tar.gz` |
| FreeBSD | `.tar.gz`; the release job is currently disabled |
| RISC-V | not shipped |

- Linux packages install a desktop entry, file types and a camera (PTP) udev rule. AppImage and Flatpak users add the rule by hand for tethering.
- Flatpak can reach the network and the Pictures folder only; widen with a Flatpak override if you keep photos elsewhere.

## Updates
- **Help ▸ Check for Updates…** reads the release feed, shows the notes and what installing does, then downloads the file for your platform.
- A download is installed only when the release's checksum list carries a valid signature; it is checked again before install.
- **Check for updates when the app starts** is off by default (Settings ▸ General ▸ Startup). Nothing else phones home.

## Display and HDR
- **Settings ▸ Display ▸ Choose Profile…** picks a monitor ICC profile; **Use sRGB** clears it. Without one, macOS and Linux use the screen's own profile; Windows reads the profile Windows assigns.
- Previews and the Detail view use the display's gamut; exports and the histogram stay sRGB.
- Linux and Windows follow only one display's profile; per-monitor follow on Windows and pure Wayland is not built.
- **HDR display** output is partial: Settings ▸ Performance ▸ *HDR display where the screen supports it* (applies at next launch).
