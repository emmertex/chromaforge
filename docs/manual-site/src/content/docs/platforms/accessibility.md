Partial.

- **Desktop** exposes an accessibility tree: VoiceOver (macOS), Narrator (Windows), Orca (Linux).
- Buttons, sliders, fields, thumbnails (name, rating, flag, label), the Map, Book, Slideshow, Print and Web panels, Metadata and Navigator are named.
- **Tab** and **Shift+Tab** move through each module's panels.
- Arrow keys nudge the crop frame and the selected spot (1 %, Shift for 10 %).
- Not yet: mask pins and brush strokes are pointer-only; a few shared widgets (filmstrip cells, search field, keyword fields, Quick Develop steppers) lack names.
- The **web build** has no screen reader support.
- Shortcuts are listed in **Help ▸ Keyboard Shortcuts** and can be changed.
