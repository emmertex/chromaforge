## Rendering
- Develop renders on the GPU (Metal, Vulkan, DirectX 12) with a CPU fallback that gives the same result.
- **Settings ▸ Performance**: *Use the GPU for rendering*, preview size, *High quality adjustment previews*, memory for caches (Automatic uses a quarter of RAM, up to 16 GB).
- **Exports**: photos at once, *Use the GPU for exports*, and **Test my machine**, which tries several settings and keeps the fastest.
- **Thumbnail cache**: size limit and **Clear Cache**.
- **Prepare photos in the background**: next photos are rendered ahead; it shows in the activity stack.
- Budgets (measured on one desktop): slider update under 16 ms, loupe under 60 ms, a 24 MP JPEG export about half a second.
- A GPU backend can be forced or turned off with an environment variable named in the developer docs, if a driver crashes.

## Activity stack
- Anything slow (import, export, previews, sync, downloads) runs off the main thread and shows as a row with a progress bar and a stop button when it can stop.
- **Classic and Compact**: in the module bar. One task shows its bar; several show "N operations in progress…"; click for the full list.
- **Modern**: a floating card under the Library / Develop switch, three rows and "+N more".
- Quitting asks first while a stoppable task is running.
