- **Copy Edit Settings** / **Paste** (`⇧⌘V`): choose which groups travel (light, colour, detail, effects, geometry, crop, masks, spots, ...). Spots and red eye stay per photo when syncing.
- **Previous** (bottom right): paste the settings of the photo you edited before onto this one. With several photos selected the button is **Sync…**.
- **Sync Settings** copies the settings you changed since the last step to the selection, as one undo step.
- **Auto Sync** (`⌥⇧⌘A`, the switch at the bottom): every slider drag edits all selected photos live.
- **Match Total Exposures** (`⌥⇧⌘M`): sets Exposure so each selected photo ends equal, from shutter, ISO and aperture.
- **Presets**: **Photo ▸ Develop Settings ▸ Create Preset…** (`⇧⌘P`) with a per-setting checklist; **Amount** 0 to 200. See [Colour, grading and profiles](../colour/).
- **Per-camera defaults**: **Settings ▸ Import** and the Optics section's save button.
- **Before / After copy**: copy After to Before or swap: see [Views and zoom](../views/).

<Aside type="note" title="Modern layout">
  **Photo ▸ Develop Settings** holds Copy, Paste, Sync, Auto Sync and Match Total Exposures.
</Aside>
