- **Light**: exposure, contrast, highlights, shadows, whites, blacks.
- **Colour**: temperature, tint, vibrance, saturation, HSL.
- **Detail**: sharpening, noise reduction.
- **Effects**: clarity, dehaze, vignette, grain.
- Double-click a slider to reset it. Every slider is also a command.
- Edits are stored as a recipe; **Before / After** shows the difference.
