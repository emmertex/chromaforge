- **Shadows Tint**: green to magenta cast in the darks.
- **Red, Green, Blue Primary**: **Hue** and **Saturation** each. Read and written in XMP.
- Different from [camera profiles](../colour/): Calibration shifts the primaries of whatever profile is active.
- **Per-camera defaults**: a camera's raws can start from their own profile: **Settings ▸ Import**.

<Aside type="note" title="Modern layout">
  **Window ▸ Edit Sections ▸ Calibration** (Classic and Compact show it in the Edit panel).
</Aside>
