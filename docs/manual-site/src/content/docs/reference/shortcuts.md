- Default **Classic** key set. On macOS read **Ctrl** as **⌘**; **Alt** is **⌥**. All keys can be changed: see [Customise shortcuts](../../automate/shortcuts/).
- Keys in a text field or dialog go to the field first. **Ctrl+/** shows the keys of the current module.
- Ratings and flags in the grids: `Shift` with a number, `P`, `X` or `U` applies the action and moves to the next photo.
- The **Alternative** set has different keys; **Edit ▸ Keymap** switches.

## Keys that depend on the module

| Key | Where | Does |
|---|---|---|
| `D` | everywhere | Develop (besides `Ctrl+Alt+2`) |
| `Ctrl+Shift+L` | everywhere | Dim the lights |
| `Home` / `End` | Library, Develop | First / last photo |
| `Ctrl+Left` / `Ctrl+Right` | Library, Develop | Previous / next photo |
| `Ctrl+Shift+U` | Library, Develop | Auto white balance |
| `Ctrl+N` | Develop | New snapshot (version) |
| `Ctrl+Shift+N` | Develop | New preset |
| `Shift+Q` | Develop | Cycle the selected spot: Remove, Heal, Clone |
| `Ctrl+Shift+H` | Develop | Always show the tool overlay |
| `O` | Library | People view |
| `Enter` | Detail, Slideshow | Done with a tool; play slideshow |
| `Ctrl+Shift+B` | Book | Add page |
| `Left` / `Right` | Print | Previous / next preview page |
| `Ctrl+R` / `Ctrl+Alt+P` | Web | Reload / preview in browser |

- In Detail, `[` and `]` resize the brush and `Shift+[` / `Shift+]` set its feather; in the grids `[` and `]` lower and raise the rating.
- `Alt+1`–`Alt+9` apply the current keyword set's keywords; `Alt+0` / `Alt+Shift+0` move to the next / previous set.
