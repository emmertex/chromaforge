Paired devices on the same network share a library directly. No account, no cloud.

<NeedsImage what="Settings ▸ Sync with a found device, the six-digit pairing code, and a paired device with the shared library" />

## Setup
- Open **Settings ▸ Sync** on both devices; both must be on the same network. Devices appear under *Find devices*.
- **Pair**: both screens show a six-digit code; both people confirm it.
- **Share the library**: offer it to a paired device; accept on the other. Both then carry the same sync id.
- The device name shown to others is set at the top of the tab.
- Works between macOS, Windows, Linux and Android, with any number of devices. A change travels across hops (A to C through B).

## What is shared
- Develop settings, rating, flag and colour label of photos that **both** libraries already hold. Photos are matched by the hash of the original file.
- Each exchange is encrypted and mutually authenticated. Exchanges run about every 15 seconds while devices see each other.
- Changes arrive as undoable steps.

## Conflicts
- A three-way merge per device pair. When both sides changed the same photo, each keeps its own edit and gets the other's as a **virtual copy** in the same stack.

## Not built yet
- Photos, albums, keywords and metadata do not travel; only photos both libraries already have are matched.
- Choosing what to sync (albums, picks) and keeping previews instead of originals are planned, not available.
- Deletions are not synced.
- Not yet tested between real devices; discovery is IPv4 only, on one network interface.

## Privacy
- Only your paired devices are contacted. Unpair every device in **Settings ▸ Sync** to stop. See [Privacy](../../platforms/settings-and-privacy/).

<Aside type="note" title="Modern layout">
  **Edit ▸ Settings… ▸ Sync**. On Android the Modern layout is the default; the same tab is in its Settings.
</Aside>
