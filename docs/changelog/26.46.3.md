# 26.46.3

## Develop and masking

- **Masking panel readability:** larger mask and component preview thumbnails, cleaner mask-tree rows without resting backgrounds, **Who**/**Role** controls hidden by default behind **Show Who & Roles** in the component menu, and a vertical checkbox list for People parts. Issue #1111.
- **Mask Hue can reach ±180°:** the mask Hue is now stored as an angle in degrees, and the new Settings ▸ Interface ▸ Expanded sliders option (off by default) widens its slider from about ±34° to ±180°. Existing edits render at the same angle; XMP keeps `crs:LocalHue` clamped to Lightroom's range and adds `lc:LocalHueDegrees` only for a value past it. Issue #1145.

## Develop

- **RGB mode for Contrast and Blacks:** a **Contrast Mode** switch (**Luminance** | **RGB**) in **Basic ▸ Tone** lets the **Contrast** and **Blacks** sliders apply their tonal response across the Red, Green and Blue channels like an RGB tone curve, enriching shadow depth and colour contrast while keeping **Luminance** as the default. Thanks @elianos-design for the report (issue #839).
- **Vignetting Calibration:** a lens's light fall-off measured from a reference raw (an OLED screen or a diffuser; works like Capture One's LCC "Uniform Light") and applied non-destructively by Develop ▸ Lens Corrections ▸ Vignetting Calibration, with an Amount slider (0 to 120). Create measures a reference after checking that the raw looks like a flat field (detail, colour, fall-off shape, exposure): a photo that clearly isn't one is refused with the reason, a borderline one asks first (Create Anyway; `force` in the command). Apply picks each photo's reference by camera model, lens, a zoom's focal length and the same aperture (within a sixth of a stop; one reference per aperture is needed), whichever body made it. Only one reference is in use per combination and image area: Create asks before replacing one (Replace; `replace` in the command), a full-frame reference also replaces crop ones it covers, a crop reference leaves the full-frame one for full-frame shots, photos that use the old one keep it, undo brings it back. Create notes when a Nikon raw records VR on. One gain for all channels: no colour-cast correction. References are stored once per catalog and referenced by the photos that use them, travel with sidecars, presets and copied settings, and are kept in a library in the settings folder. Stop Using as Reference withdraws a reference (Apply skips it; photos keep it; one undo step), and the photo is a normal photo again until Create measures it again; undoing a Create withdraws its reference. A Library filter (`vignettingReference`: reference or none), a smart-collection rule (Vignetting Reference) and a grid marker find references in use. Commands: `vignettingCalibration.create`, `vignettingCalibration.apply`, `vignettingCalibration.remove`, `vignettingCalibration.list`, `vignettingCalibration.photo`, `vignettingCalibration.showReference`, `vignettingCalibration.withdraw`, `vignettingCalibration.restore`, `vignettingCalibration.references`. The catalog format goes to 18: older builds refuse a library this build has opened.

## Library

- **Edited capture times keep their time zone:** Edit Capture Time (`photo.setCaptureTime`) keeps a UTC offset typed with the time (`…+01:00`) instead of dropping it, so the corrected time exports with `OffsetTimeOriginal`; one photo gets the time as typed.
- Advanced Search: expanded categories collapse again when their header is clicked (#1134).
- **Better face matching**: each face is averaged with its mirror image before it is compared with named faces, so the same person matches more often. Scanning takes about twice as long and faces scanned before are embedded once more. An option in Settings ▸ Faces ▸ Matching (on by default) turns it off.
- **People view follows the sidebar:** picking a folder, a collection or Missing Photos now narrows the named people and their counts to those photos (issue #1131).

## Fixes

- **Importing presets from Library:** the presets go to Develop's Presets panel instead of opening the presets column in place of the Edit panel, which left Develop with presets and no sliders (issue #875).
- **GPU stays off after a graphics-driver reset:** when the window stopped drawing after the GPU was lost for the first time in a session, the next start didn't switch to rendering on the CPU and the message didn't say the GPU was lost; only a loss after the recoveries had run out was recorded.
- **Calibrated camera profiles:** the profile's camera name no longer repeats the make when the model already starts with it ("Canon EOS 6D", not "CANON Canon EOS 6D"), so such an imported profile shows in the Camera Profiles menu (#1119).
- **Nikon distortion correction set to Off**: Z-body NEFs whose in-camera distortion correction is Off (mode 2), or whose mode is unknown, are no longer warped; only "On (Optional)" and "On (Required)" are. Previews already built for such files keep their old look until they are rebuilt.

## Metadata

- **Same capture time for every selected photo**: Edit Capture Time has a "Give every selected photo this time" option for several photos, and its note says which of the two will happen.

## Export

- **Queued exports**: an export asked for while another runs waits its turn in the activity stack instead of being refused, and is checked against the originals as they are when it starts.

## Fixed

- Keywording panel chips show the keyword's own name instead of its whole hierarchy path (#1132).
- Original export with "Remove location" fails closed on every embedded XMP packet, altitude and place-name properties, truncated PNG/WebP chunk streams and over-limit XMP.
