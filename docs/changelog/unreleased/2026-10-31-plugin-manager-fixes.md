## Fixes

- **Plug-in Manager fixes:** the window opens at its usual width whatever is installed (a pixel filter with many parameters made it nearly as wide as the screen, and it only got wider) and drags narrower as well as wider, with a page's text and the folder line wrapping or shortening to fit. While the install dialog waits, another module is refused with a note to finish the first instead of replacing it. A module that is exactly what is installed selects its entry instead of asking again (`plugin.inspectFile` gives `installed.same`; `plugin.list` gives a plug-in's `moduleHash` and `settingsRevision`). An open Settings tab shows an update's fields and values the plug-in set itself, keeping what was typed and not saved, so *Save* no longer writes old values over newer ones. "Plug-in Manager" is the one spelling in messages and docs.
