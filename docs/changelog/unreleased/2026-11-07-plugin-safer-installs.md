## Plug-ins

- **Safer installs and updates:** an update keeps the version it replaced, and *Go Back to Version X* (`plugin.rollback`) restores it with its settings; Remove asks first and can keep a plug-in's data and settings (`plugin.uninstall {keepData}`); installs name unknown manifest fields; a plug-in and a pixel filter can't share an id, a second module with an id is listed instead of hidden, and modules past the folder's limit are counted; older pixel filters need confirming.
