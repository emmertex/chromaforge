## Fixes

- **Canon EOS 7D framing:** CR2 files whose camera JPEG shows the whole frame no longer take the maker note's aspect crop (a 7D was cropped to 4:3). Issue #964.
- **Startup error:** the silent check for an older install's presets no longer shows an error when there is none. Issue #965.
- **Unreadable folders:** browsing a folder that can't be listed shows the reason instead of an empty "No photos in this folder". Issue #966.
