## Library

- **Import tab, from OneSlips (the new default):** Import and Library workspace tabs; the Import tab browses a card or
  folder for culling and imports its picks, selection or all (`import.start`, `import.run`, `import.targets`), with a
  preset stack (`library.import` `presets`), import presets and previews built afterwards (`library.finishImport`).
  Browsed photos join the library with their culling (copied or moved, the record follows its file) and are never
  deleted, renamed or moved before that. Settings ▸ Import ▸ Import as a tab switches back to the import review.
  Thanks @OneSlips. (no PR)
