## Interface

- **UI polish:** one Libraries menu, Import beside the modules, a dismissable title-bar message, and a single Settings ▸ AI Models page for every model download and the SAM 3 folder. The Modern layout gets a second bar for delete, flag, rating and Info. Export is a module at the far right of the top bar, with a preview of the photos and the settings in a resizable column (touch layouts keep the dialog).
- **Faces:** Detect Faces runs in the background (no frozen window), Library ▸ Clear Faces and Rescan starts the scan again, and the scan drops detections FaceMesh doesn't confirm.
