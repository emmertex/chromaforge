## Import

- **Capture One catalog import:** File ▸ More Imports ▸ Import Lightroom or Capture One Catalog… also reads a Capture One catalog (`.cocatalogdb`, Capture One 16.9.0 checked) into the same import as Lightroom's: originals in the catalog or referenced, variants as virtual copies, star ratings, colour tags (orange and pink without a label), IPTC fields, hierarchical keywords, and albums with their projects and groups; smart albums, trashed images, files of a type the app doesn't read (such as `.NEFX`) and Capture One's own folders are left out with a warning, and develop settings are not read yet. The import's windows, messages, undo step and file dialog (a filter for each catalog kind) name the program the catalog comes from. (no PR)
