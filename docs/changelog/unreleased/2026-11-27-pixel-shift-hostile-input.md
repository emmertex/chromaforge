## Import, export and formats

- **Pixel Shift merges are read safely from files that someone may have crafted:** the provenance block of a merged DNG and the maker notes of the frames are bounded (packet size, shot count, frame numbers, string lengths, the sensor window, and the per-frame models of a registered merge, the tile count and the time it was made) and a block that breaks a limit is no block: the DNG opens as the normal DNG it is. A value a newer version may write (a method, a verdict, a reason or an engine number this version does not know) reads as unknown and never makes a file or the library unreadable. When a merged DNG is imported on its own, its frames are found in the library again only when everything agrees: same folder, file name and capture time, the frame's own maker note giving the listed frame number and exposure counter, and all the frames together being one series; otherwise none is found and **Delete Merge Sources** has nothing to act on, so a crafted DNG can no longer send unrelated photos to Recently Deleted. Several merges of one stack that list the same frames are each checked on their own; after the first Delete Merge Sources the others find the frames missing and touch nothing. Seeded mutation tests of both readers run in the test suite (`LCC_FUZZ_ITERS` makes them longer). Rules and limits: `docs/pixel-shift.md`.
