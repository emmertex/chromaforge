## Import

- **Several drives at once:** the import scan, Synchronize Folder and the command-line Lightroom import read files per drive, side by side, each drive starting with as many readers as before (then finding its own number: see "Each drive finds its own number of readers"). A drive that stops answering has its files reported as "volume not responding" while the others go on, Cancel returns even while a drive hangs, and a file that crashes the reader fails alone.
