## Interface

- **Presets Manager rebuilt for large collections:** the manager opens at a size that fits the screen, keeps the size you drag it to (remembered across restarts) and no longer widens itself past the screen. It is drawn as a table with the actions in fixed columns (At Import, Rename, Group, Hide, Delete), a group's Delete asks at the group and can move its presets to another group first, Ctrl-click and Shift-click pick several presets to drag onto a group, and double-clicking a name renames it. With 10 000+ presets only the rows in view are laid out. Based on work by @OneSlips.
