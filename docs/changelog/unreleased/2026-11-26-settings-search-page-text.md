## Interface

- **Settings search reads the whole page:** the search field over the list of Settings pages now looks at everything a page shows, in the app's language, and at the command ids of its settings, and marks the matches in the open page. Before, it knew only the page names and a fixed English word list per page.
- **Settings ▸ Interface:** the Dark Theme card comes before the Light Theme card, as the Dark Mode and Light Mode buttons above them do.
