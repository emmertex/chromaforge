## Interface

- **Browse (was Import):** the import tab — a folder or card culled without importing — is renamed Browse, with
  Photo Grid / Grid / Detail views in its bar and a **Develop without Import** button: develop the selected photo in
  place, the edit saved to its XMP sidecar and the catalog untouched (`import.develop`; the module bar's Develop and
  the D shortcut do the same while a folder is browsed). A quick filter, **Show All / Show Not Imported**
  (`library.browse {show}`): the default view is the files an import would take; Show All adds the ones the library
  has already, marked In library on their cells. The Library Folders panel lists only the folders the library's
  photos were imported from, no empty disk folders around them. A deliberate divergence from the reference app's
  naming and Folders listing.
