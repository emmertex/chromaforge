## Develop

- **Before / After:** Before is the import state; Set Before is kept with the photo (catalog format 16, `Op::SetBefore`, `Photo.before`, `Photo.import_state`; older catalogs read unchanged). LrC shortcuts for Copy After→Before (⌘⌥⇧←), Before→After (⌘⌥⇧→) and Swap (⌘⌥⇧↑). Thanks @OneSlips. (no PR)
