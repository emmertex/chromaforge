## Library

- **One name and one recent list for libraries:** File ▸ Libraries, the welcome window, the launch list and the `catalog.*` commands share one recent list (an older recent catalogs list is carried over once), Settings ▸ General ▸ At launch is the one startup choice, holding Alt opens one window, Back Up Library is in File ▸ Libraries on the desktop, and every text about the library folder says library. Command ids are unchanged.
