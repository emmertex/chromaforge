## Import

- **Work on browsed photos without importing them:** Develop, Print, Export and Slideshow chosen from the Browse tab (module picker, shortcuts, File ▸ Export…) open on the selected photo in place, and from a browsed photo in Develop, Print and Export no longer jump back to Browse; a file already in the library opens as its catalog photo. The Browse bar's buttons are now Import and Develop, without the duplicate Photo Grid / Grid / Detail switch.
