## Develop

- **Base curve:** a raw photo can take its base tone from a curve file instead of its camera look's tone or the generic raw curve. Nothing is bundled: the files are plain JSON in the `base-curves` folder of the settings folder (or the folder named by `<PREFIX>_BASE_CURVES`), and the Profile section lists them in a new Base curve row (a filter narrows long lists, Refresh scans the folder again). The format is documented in `docs/base-curve-format.md`: named curves with linear or monotone cubic interpolation, an ordered list of steps (a curve on luminance, a curve on each channel, a mix), and the extension beyond the last point. This version renders luminance steps; a file with other steps is listed as not supported. The curve replaces the base tone (nothing of the camera look's tone is applied), Contrast, Whites and Blacks act on its output without a shoulder of their own and are exactly the identity at 0, and an HDR edit lifts the highlights above it as for every base tone. A photo whose curve file is missing keeps the choice, renders with the default base tone and says so in the panel and in an export's warnings. The setting (`profile.base_curve`, an id `base:<file name>`) is left out of the JSON while empty, so no existing edit or hash changes; the curve file's content is part of the settings hash. Stored in the app's own settings only (nothing is written to `crs:`); not the Tone Curve tool.
