## Develop

- **Base curve:** a raw photo can take its base tone from a curve file instead of its camera look's tone or the generic raw curve. Nothing is bundled: the files are plain JSON in the `base-curves` folder of the settings folder (or the folder named by `<PREFIX>_BASE_CURVES`), and the Profile section lists them in a new Base curve row (a filter narrows long lists, Refresh scans the folder again). The format is documented in `docs/base-curve-format.md`: named curves with linear, monotone cubic or (format version 2) natural cubic spline interpolation, an ordered list of steps (a curve on luminance, a curve on each channel, a mix, and from version 2 an encode and a decode step that let a file carry a whole neutral transfer), an input gain that can leave headroom above the sensor's white, and the extension beyond the last point. This version renders luminance steps and the encode and decode steps; a file with other steps is listed as not supported. The curve replaces the base tone (nothing of the camera look's tone is applied), Contrast, Whites and Blacks act on its output without a shoulder of their own and are exactly the identity at 0, and an HDR edit lifts the highlights above it as for every base tone. A photo whose curve file is missing keeps the choice, renders with the default base tone and says so in the panel and in an export's warnings. The setting (`profile.base_curve`, an id `base:<file name>`) is left out of the JSON while empty, so no existing edit or hash changes; the curve file's content is part of the settings hash. Stored in the app's own settings only (nothing is written to `crs:`); not the Tone Curve tool.
- **Base curve, channel share:** a curve file (format version 2) may set `channel_share`, 0 to 1 (default 0). With a share above 0 the render blends, by that share, the luminance result (the colour follows by ratio, as before) with the curve run on each colour channel in linear Rec.709 (negative channels as 0), before the hue-preserving highlight clip: saturated mid-tones gain and bright saturated colours roll towards white as with a curve applied per channel. Grey is unchanged, and without the field the render is exactly as before. Done on the CPU and the GPU.
