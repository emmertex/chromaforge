## Interface

- **Settings shows every tab at once:** the Classic Settings window opens as wide as its row of tabs and as tall as
  the screen allows (up to 1340 points), so no tab is under More until the window is made narrower. Its pages use a
  plain layout: a bold header and hairline per section, labels left-aligned in a 170-point column, small side-by-side
  choice buttons, and grey help text wrapping at 680 points. A size the user chose is kept; the old 900 × 640 default
  counts as never chosen. The Modern layout's Settings is unchanged. Thanks @OneSlips.
