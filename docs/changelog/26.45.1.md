# 26.45.1

## Fixes

- **Settings, library and AI models carry over from the previous app name again:** 26.45.0 opened its log file in the new Chromaforge settings folder before copying the old folder, so the copy was skipped and the app forgot the last library, the AI models and the plug-ins. The copy now runs first, and also fills a Chromaforge folder that holds nothing but logs.
  If 26.45.0 already started once and Chromaforge has settings of its own, copy the missing items by hand: quit Chromaforge, open the folder that holds the settings folders, and copy everything from the previous app's folder (the one named after the old app) into the Chromaforge folder, skipping files that already exist there. Reopen your library with File ▸ Open Recent Catalog… or Open Catalog…
  - **Windows:** `%APPDATA%` (paste it into the Explorer address bar): copy from the old app's folder into `Chromaforge`.
  - **macOS:** `~/Library/Application Support` (Finder ▸ Go ▸ Go to Folder…): copy into `Chromaforge`.
  - **Linux:** `~/.config` (or `$XDG_CONFIG_HOME`): folder names are lower-case; copy into the folder named after the current app.
