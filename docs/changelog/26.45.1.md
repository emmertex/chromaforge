# 26.45.1

## Fixes

- **Settings, library and AI models carry over from LightCraft Classic again:** 26.45.0 opened its log file in the new Chromaforge settings folder before copying the old folder, so the copy was skipped and the app forgot the last library, the AI models and the plug-ins. The copy now runs first, and also fills a Chromaforge folder that holds nothing but logs. If 26.45.0 already hit you and Chromaforge has settings of its own, copy what's missing from `%APPDATA%\LightCraft Classic` (macOS: `~/Library/Application Support/LightCraft Classic`) by hand.
