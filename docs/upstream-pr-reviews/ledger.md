# Upstream intake ledger

Single source of truth for what we decided about each upstream PR and commit. The procedure is
[`docs/upstream-pr-intake.md`](../upstream-pr-intake.md); the older files in this directory are the **frozen archive**
of the 2026-10 reviews and are not edited.

**Round 1 (2026-11-02) scope.** Upstream was 3,300 PRs deep and 126 open PRs sat above the old #3306 boundary, so the
round triaged every one by path class and read the small shared-crate fixes in full. Deep reads (diff, body, tests,
fork code): #3298, #3370, #3414, #3422, #3441-#3448, #3464-#3470, #3495, #3512, #3515, #3523, #3567, #3574. The rest
are recorded `PENDING` with what is missing — mostly upstream-owned UI/perf/AI work whose shared files are plumbing.
Rows marked "already in the fork" name the earlier port commit, which the ledger had not recorded.

The next round starts with the `PENDING` rows below, then every PR updated since 2026-11-02. Use
`python3 tools/upstream_intake.py enumerate --since 2026-11-02`.

`PENDING`, `WATCH`. `Recheck` says what re-opens the row (`-` for a final decision). `Upstream ref` is the reviewed
PR head or commit SHA. A pipe inside a cell is escaped with a backslash.
